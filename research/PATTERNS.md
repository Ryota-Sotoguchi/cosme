# 伸びているアカウントから取り出した型

監視対象（[accounts.md](accounts.md)）の投稿を分析して、
**うちの制約の中で使えるものだけ**を抜き出したもの。

投稿文の変更は、最終的にここに書かれた型を `src/content/` に落とし込む形で行う。

---

## 採用できる型

### P1. 1行目で対象を名指しする

参考先は例外なく1行目に対象が出てくる。

    たるみは皮膚が伸びたんじゃない。
    ナイアシンアミドはヤバい成分です。
    コスデコの値上げ辛い😭😭
    全身クレドなんて厳しい。

おすすめ欄に流れてきた人は、そのアカウントが何のアカウントか知らない。
1行目に対象が無いと、何の話か分からないまま流される。

→ **2026-08-23 に適用済み。** 買い物・選び方の投稿81件の1行目に対象語を入れ、
`test_no_link_topics_name_their_subject_in_the_first_line` で固定した。

### P2. 立場を持った言い切りで始める

    死ぬまで言うけど、
    炎症覚悟で言うけど、
    5億回は言ってるけど、
    これ知ってたら資生堂マニア。

「〜かも」「〜な気がする」で始まらない。強い言い切りで止めてから、
2本目以降で理屈を足していく。

**うちで使えるのは「買い方の主張」まで。** 商品の良し悪しや効能は言い切れない
（使っていないし、根拠がない）が、「一番安い店を探し続けるのは損」のような
買い物の考え方は言い切ってよい。

### P3. 読み手を名指しで絞る

    30代後半で美容医療デビューする人、カウンセリング行く前にこれだけ持ってって。

全員に向けて書かず、対象を絞る。絞ったほうが刺さる人には強く刺さる。

→ リンク投稿の書き出しに一部導入済み（`ro_forwho`「{category}探してる人、これ見てみてほしい」）。
まだ「はじめて買う人」「切らしそうな人」など、絞り方の幅が足りない。

### P4. 番号つき・箇条書きで分解する

    ① 資生堂 スポンジクリーナー（440円）
    ・アイブロウ / マスカラ → 資生堂のプチプラ〜中価格

箇条書きは保存されやすい。番号つきは「順番がある」ことを示せる。

→ 一部導入済み（`benefits.py` の tips、`HOWTO_POSTS`）。
**番号つき（①②③）はまだ使っていない。** 「順番」を示す投稿では番号のほうが合う。

### P5. 連投で「フック → 理屈」に分ける

参考先は1本目で言い切り、2本目で理由を並べる。
1本目だけ読んで離脱しても意味が通り、続きが気になる人だけ2本目に進む。

→ 導入済み（リンク投稿は2〜4本構成）。リンクなし投稿はまだ1本で完結している。
**つぶやきや ノウハウでも連投にする余地がある。**

### P6. 保存を促す

    保存必須なんだけど…

→ 一部導入済み（`hw_first_cosme` の「保存しておくと買い物のとき見返せます」）。
全ての箇条書き投稿には入っていない。

## 採用できない型（記録として残す）

真似したくなるが、うちでは使えないもの。**繰り返し検討しないよう理由ごと残す。**

| 型 | 例 | 使えない理由 |
|---|---|---|
| 体験談 | 「白湯を毎朝3週間続けたら、顔色が別人になった」 | 商品を使っていない。捏造になる |
| 効能の断定 | 「3ヶ月でくすみが変わった方法」 | 薬機法。一般化粧品で言えるのは56項目のみ |
| 成分の効果主張 | 「ナイアシンアミドはヤバい成分です」 | 同上。配合成分の効果は標ぼうできない |
| 美容医療の解説 | ハイフ、注入、糸リフト | `config.toml` の `[exclusion]` で除外中のカテゴリー |
| 煽り | 「売り切れる前に急げー！！！！！」 | 景表法（有利誤認）。在庫を確認していないので事実を保証できない |
| 権威づけ | 「美容皮膚科の先生に教えてもらった」 | 取材していない。捏造になる |
