---
description: 他人の投稿への返信案を作る（投稿は人が確認してから）
---

返信候補を読んで、その投稿に合った返信案を作る。**投稿はしない。**

## 1. 候補を読む

**公式検索で引く。** ここでしか `post_id` が取れず、
post_id が無いと API から返信できない。

    .venv/bin/python -m src.main engage --search 転職 --limit 10

反応数まで見たいときは、スクレイプした候補と併せて読む。
公式検索はいいね数・返信数を返さないため。

    ls -t research/replies/ | head -3

すでに返信した相手は避ける。

    .venv/bin/python -m src.main engage --history

## 2. 投稿を読んでから書く

**必ず本文を読んでから返信を作る。** テンプレを当てはめない。

その投稿に出てくる具体（職種・年収・悩み・状況・言い回し）に触れる。

発信ジャンルは 2026-09-14 から転職・年収・キャリア。返信先の話題は問わない。
中の人は転職を二回している会社員で、面接官として採用にも関わっている（`src/content/persona.py`）。

    投稿  「28歳、事務職で年収380万。転職したいけど、
           何から始めればいいのか分からなくて止まってる」

    ○  事務職のままでも、職務経歴書を一度書いてみると動きやすくなりますよ。
       書くと、自分が何を任されてきたかが見えてきますので
    ×  わかります！転職って大変ですよね！

## 3. 型を散らす

毎回同じ形にしない。投稿に合わせて選ぶ。

| 型 | 使いどころ |
|---|---|
| 共感 | 悩み・ぼやきの投稿 |
| 質問 | 転職活動・面接・職場の報告。相手が答えやすいものを |
| 感想 | 意見・考察の投稿 |
| 経験 | 同じ状況の話（自分の転職・面接・職場の経験は書いてよい）。**年収の自慢や、使ってもいないサービスの体験は書かない** |
| 補足 | 相手が困っている投稿。軽く情報を足す |

**毎回質問で終わらせない。**

## 4. 文体 — **返信はすべて敬語（です・ます）**

投稿（`src/content/parts.py`）は話し言葉のままだが、**返信は敬語に統一する**
（2026-09-14）。知らない人のコメント欄に書くので、タメ口は馴れ馴れしく見える。

- すべての文を「です」「ます」で終える
  - ○「つい逃しちゃいますよね」 ×「つい逃しちゃうよね」
  - ○「わたしも見てます…眠くなりますね」 ×「わたしも見てる…眠くなりますね」
- 硬い敬語は使わない（「させていただきます」「でございます」）。やわらかい丁寧語で
- 絵文字は多くて1つ。無しでもいい
- 長文にしない（だいたい50字以内）
- 「！」を連発しない
- 過剰に褒めない

`engage --check` がタメ口の文を見つけると落とす（`src/engage/review.py` の
`impolite_fragment`）。

## 5. 書いてはいけないもの

- **URL・リンク**（コメント欄のリンクは宣伝に見える。ただのURLも入れない）
- 自分の投稿・アカウントへの誘導
- 保証・断定（「必ず内定が出ます」「絶対に年収が上がります」）
- 統計の断定（「平均年収は○万円」「○割の人が〜」）
- 断定的な法的助言（「それは違法です」「訴えれば勝てます」）
- 実在する会社の名指しの批判・中傷
- 副業や投資の勧誘、稼げる系への誘導
- 年齢・性別で可能性を決めつける言い方
- 使ってもいないサービスの体験談
- 相手の年収や経歴を下に見る言い方、相手を否定する内容
- センシティブな話題（ハラスメント被害・メンタル不調・解雇トラブル）への深入り

## 6. 自分で検査する

作った返信案を全部通す。

    .venv/bin/python -m src.main engage --check "返信文をここに"

URL・NG表現・長さ・テンプレ度を見る。落ちたら書き直す。

## 7. 出す

候補ごとに、返信案を並べて表示する。**あなたが見てから投稿する。**

    # 検査だけ（投稿しない）
    .venv/bin/python -m src.main engage \
      --reply-to <username> <post_id> --text "返信文"

    # 確認したら投稿
    .venv/bin/python -m src.main engage \
      --reply-to <username> <post_id> --text "返信文" \
      --shortcode <短縮ID> --live

post_id が取れていない候補（スクレイプだけで見つけたもの）は
API から返信できないので、パーマリンクを開いて手で返す。
その場合は記録だけ残す。

    .venv/bin/python -m src.main engage --mark <username> <shortcode>

## 注意

- 1日3件まで。Metaのスパム規定は頻度を見る
- 同じ相手には週に1回まで
- 数を追わない。返す価値のある投稿だけに返す
