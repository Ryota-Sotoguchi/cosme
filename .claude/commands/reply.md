---
description: 他人の投稿への返信案を作る（投稿は人が確認してから）
---

返信候補を読んで、その投稿に合った返信案を作る。**投稿はしない。**

## 1. 候補を読む

**公式検索で引く。** ここでしか `post_id` が取れず、
post_id が無いと API から返信できない。

    .venv/bin/python -m src.main engage --search コスメ --limit 10

反応数まで見たいときは、スクレイプした候補と併せて読む。
公式検索はいいね数・返信数を返さないため。

    ls -t research/replies/ | head -3

すでに返信した相手は避ける。

    .venv/bin/python -m src.main engage --history

## 2. 投稿を読んでから書く

**必ず本文を読んでから返信を作る。** テンプレを当てはめない。

その投稿に出てくる具体（商品名・悩み・状況・言い回し）に触れる。

    投稿  「34歳です。無印の化粧水と乳液しかしていません。
           超敏感肌、オイリー肌、シミに悩んでいます」

    ○  無印だけでも十分だと思います〜。敏感肌だと足すほど荒れること
       あるので、まずは日焼け止めだけ足すのがいいって聞きました
    ×  わかります！わたしも悩んでます！

## 3. 型を散らす

毎回同じ形にしない。投稿に合わせて選ぶ。

| 型 | 使いどころ |
|---|---|
| 共感 | 悩み・ぼやきの投稿 |
| 質問 | レビュー・購入品の投稿。相手が答えやすいものを |
| 感想 | 意見・考察の投稿 |
| 経験 | 同じ状況の話。**使ってもいない商品の体験は書かない** |
| 補足 | 相手が困っている投稿。軽く情報を足す |

**毎回質問で終わらせない。**

## 4. 文体

`src/content/parts.py` で決めた語り口をそのまま使う。

- 終止形で言い切らない（「逃す」ではなく「逃しちゃう」）
- 絵文字は多くて1つ。無しでもいい
- 丁寧すぎない。長文にしない（だいたい50字以内）
- 「！」を連発しない
- 過剰に褒めない

## 5. 書いてはいけないもの

- **URL・リンク**（楽天アフィリエイト規約でコメント欄への
  アフィリエイトリンクは禁止。ただのURLも入れない）
- 自分の投稿・アカウント・商品への誘導
- 効能の断定（薬機法。リンクが無くても効く）
- 使ってもいない商品の使用体験
- 相手を否定する内容
- センシティブな話題への深入り

## 6. 自分で検査する

作った返信案を全部通す。

    .venv/bin/python -m src.main engage --check "返信文をここに"

URL・NG表現・長さ・テンプレ度を見る。落ちたら書き直す。

## 7. 出す

候補ごとに、返信案を並べて表示する。**あなたが見てから投稿する。**

    # 検査だけ（投稿しない）
    .venv/bin/python -m src.main engage \
      --reply-to <username> <post_id> --text "返信文"

    # 確認したら投稿
    .venv/bin/python -m src.main engage \
      --reply-to <username> <post_id> --text "返信文" \
      --shortcode <短縮ID> --live

post_id が取れていない候補（スクレイプだけで見つけたもの）は
API から返信できないので、パーマリンクを開いて手で返す。
その場合は記録だけ残す。

    .venv/bin/python -m src.main engage --mark <username> <shortcode>

## 注意

- 1日3件まで。Metaのスパム規定は頻度を見る
- 同じ相手には週に1回まで
- 数を追わない。返す価値のある投稿だけに返す
