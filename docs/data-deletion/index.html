データ削除リクエスト

cosme が保持するデータの削除を依頼する方法。

このアプリは第三者の個人データを取得・保存していません。
アクセスするのは運営者本人の Threads アカウントのみです。他のユーザーのプロフィール、投稿、フォロー関係などを取得することはありません。

保存しているデータ

保存先内容
data/history.jsonl運営者自身の投稿記録（投稿日時、投稿ID、紹介した商品の公開情報、投稿本文）
data/state.json投稿ローテーションの位置、アクセストークンの有効期限

アクセストークンなどの認証情報はリポジトリに保存されず、GitHub Secrets で管理されています。 アフィリエイトURLも保存時にハッシュ化され、原文は残りません。

削除を依頼する

次のいずれかの方法でご連絡ください。

  • GitHub Issue を作成する — 削除を希望する内容（投稿URLなど）を記載してください
  • Threads で @cosme_memo_jp に連絡する

ご依頼から 30日以内 に該当データを削除し、削除完了をご連絡します。

投稿そのものの削除

Threads 上の投稿の削除を希望される場合も、上記の窓口までご連絡ください。 投稿本体と、リポジトリ内の該当記録の両方を削除します。

技術的な注意

このページは静的ホスティング（GitHub Pages）で配信されているため、 Meta のデータ削除コールバック（signed_request を含む POST リクエスト）は 処理しません。このアプリは Meta の認可フローを使用せず、運営者本人のアカウントにのみ 投稿する構成のため、Meta からこのコールバックが送信されることはありません。 削除のご依頼は上記の窓口で受け付けています。
