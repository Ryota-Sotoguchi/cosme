cosme

楽天市場の商品を、価格・レビュー・送料などの公開情報だけで紹介する Threads アカウントの自動運用システムです。

アカウント：コスメ買い物メモ｜コスパ美容
ソースコード：github.com/Ryota-Sotoguchi/cosme（オープンソース）

このアプリが行うこと

  • 楽天ウェブサービスの商品検索APIから、化粧品カテゴリーの商品情報を取得する
  • 価格・レビュー件数・レビュー平均・送料の有無などから、紹介する商品を選ぶ
  • 取得した客観情報だけを使って投稿文を組み立てる
  • 運営者本人の Threads アカウントに、1日5回、自動で投稿する

このアプリが行わないこと

  • 運営者以外のユーザーのアカウントにアクセスすること
  • 他のユーザーの個人データを取得・保存すること
  • 商品を実際に使用した体験談や、取得していない口コミを書くこと
  • 効能・効果に関する表現を用いること

取り扱うデータ

このアプリが保存するのは、運営者自身の投稿に関する記録だけです。

保存先内容
data/history.jsonl投稿日時・投稿ID・紹介した商品の公開情報・投稿本文
data/state.json投稿ローテーションの位置、アクセストークンの有効期限

第三者の個人データは一切取得・保存していません。 アクセストークン等の認証情報はリポジトリに保存されず、GitHub Secrets で管理されます。

  • プライバシーポリシー
