アプリ連携の解除

cosme との連携を解除したときの取り扱いについて。

保持している第三者のデータはありません。
このアプリは運営者本人のアカウントにのみアクセスします。他のユーザーのデータを取得・保存することはないため、連携解除時に削除すべきデータは存在しません。

連携を解除する方法

  • Threads アプリ → 設定 → アカウント → ウェブサイトのアクセス許可
  • 一覧から cosme を選び、アクセスを削除する

解除すると、このアプリが保持していたアクセストークンは無効になり、投稿は停止します。

解除後に残るもの

このアプリが保存しているのは、運営者自身が過去に投稿した内容の記録 （投稿日時、投稿ID、紹介した商品の公開情報、投稿本文）だけです。 これらは 公開リポジトリ 内の data/ に保存されています。

連携解除後にこの記録の削除を希望する場合は、 データ削除リクエスト の手順に従ってください。

技術的な注意

このページは静的ホスティング（GitHub Pages）で配信されており、 POST リクエストを処理しません。このアプリは Meta の認可フローを使用せず、 アプリダッシュボードで発行したトークンで運営者本人のアカウントにのみ投稿するため、 Meta から連携解除の通知が送信されることはありません。
