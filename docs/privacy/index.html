プライバシーポリシー

cosme（コスメ買い物メモ｜コスパ美容）における情報の取り扱い。

1. 運営者

個人による非商用プロジェクトです。ソースコードは GitHub で公開しています。

2. 取得する情報

このアプリが取得するのは次の3種類だけです。

  • 楽天ウェブサービスの商品情報 — 商品名、価格、レビュー件数、レビュー平均、送料区分、ポイント倍率など、楽天市場で公開されている情報
  • 運営者自身の Threads 投稿結果 — 投稿ID、投稿日時、投稿本文
  • Threads の公開投稿 — 他のユーザーが公開している投稿の本文、 ユーザーネーム、投稿URL、投稿日時、および公開されている反応数

公開投稿を取得するのは、その投稿に返信するためです。 キーワード検索で見つけた投稿の内容を読み、それに沿った返信を書きます。 返信は運営者が内容を確認してから行います。

取得するのは Threads 上で誰でも閲覧できる公開情報だけです。 非公開アカウントの投稿、フォロー関係、他のユーザーのインサイト、 メールアドレスなどの連絡先は取得しません。

3. 情報の利用目的

  • 紹介する商品の選定
  • 同じ商品を短期間に繰り返し投稿しないための重複判定
  • 投稿内容が過去の投稿と似すぎていないかの確認
  • 返信する価値のある公開投稿を見つけ、その内容に沿った返信を書くこと
  • 同じ相手や同じ投稿に繰り返し返信しないための重複判定

4. 保存場所と保存期間

他のユーザーの公開投稿は、公開リポジトリに保存しません。 返信先を選ぶ作業中にのみ使用し、非公開の保管領域に最大90日間だけ保持したうえで 自動的に破棄されます。

返信した記録として data/engagements.jsonl に、相手のユーザーネーム・ 投稿ID・返信日時・運営者が書いた返信本文を保存します。 同じ相手や同じ投稿に繰り返し返信しないために必要な最小限の情報で、 相手の投稿本文は保存しません。

運営者自身の投稿記録は公開リポジトリ内の data/history.jsonl に保存されます。 重複判定に使用するため、削除の依頼がない限り保存されます。

アクセストークン、APIキー等の認証情報はリポジトリに保存されません。 GitHub Secrets に暗号化して保管されています。アフィリエイトURLは保存時にハッシュ化され、 原文は残りません。

5. 第三者提供

取得した情報を第三者に提供・販売することはありません。

6. アフィリエイトについて

このアカウントの投稿には楽天アフィリエイトのリンクを含むものがあります。 その場合は投稿の冒頭に #PR と明示しています。 リンク経由での購入に対して運営者が報酬を受け取ることがあります。

投稿内容は楽天ウェブサービスから取得した投稿時点の公開情報に基づきます。 価格・在庫・ポイントは変動します。商品を実際に使用した体験談や、 取得していない口コミを記載することはありません。

7. 削除の依頼

データ削除リクエストをご覧ください。
