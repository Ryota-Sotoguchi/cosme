このページについて

このアプリは、運営者本人のアカウントに投稿するためだけに Threads API を使用しています。 通常の運用ではアクセストークンを Meta アプリダッシュボードで直接発行しているため、 この認可フローは使用されません。

このページは、認可フローを使う場合に認可コードを受け取るためのリダイレクト先として用意されています。 受け取った値はこのブラウザの画面に表示されるだけで、どこにも送信・保存されません。
